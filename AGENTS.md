# Fallen Paths — agent / IDE notes

Godot **4.x** project. Primary language: **GDScript**.

- **Paths:** Use **forward slashes** in `res://...` preloads and when citing repo files (`combat/Foo.gd`). Git stores paths that way; on Windows a shell may show backslashes for the same path—there is only one file.

## Combat

- Orchestrator: `combat/CombatManager.gd` (instantiated by `ui/BattleScene.gd` using `ResourcePaths.COMBAT_MANAGER`).
- **Formation doctrine at `start()`:** optional `manager.encounter` keys `ENCOUNTER_KEY_FORMATION_DOCTRINE_PLAYER` / `ENCOUNTER_KEY_FORMATION_DOCTRINE_ENEMY` (else short aliases when canonical is empty; read **`CombatConstants.encounter_formation_doctrine_string`** → **`formation_doctrine_string_from_dict`**), then optional preset fields `FORMATION_PRESET_KEY_DOCTRINE` or `FORMATION_PRESET_KEY_DOCTRINE_ALT` on each `start(player_formation, enemy_formation)` dict (preset overrides encounter per side; preset read **`CombatConstants.formation_doctrine_string_from_dict`**). Harnesses `CombatRegressionHarness._run_encounter_formation_doctrine_on_start`, **`_run_encounter_formation_doctrine_string_helper`**.
- **Health / wounds node:** `CombatManager.get_health_entity(node)` — combat subsystems should use `CombatantEntityAccess.get_health_entity_from_node(manager, node)` or `get_entity_from_manager(manager, combatant)` (not `_get_entity` from outside the manager).
- **Formation dict keys (file index as int or string):** `CombatFileKeyedDict.get_value` and `FormationBreachRules.breached_file_severity` where relevant.
- Gameplay logic is split across `combat/*.gd` modules (tick, events, formation, engagement, snapshot, medical coordination, etc.); see `.cursor/rules/fallen-paths.mdc` for a fuller map. **`ZoneOfControl.formation_dict_for_zone_geometry(manager, combatant)`** returns **`manager.formations[fid]`** for **`formation_id_for_zone_geometry`** (read-only; use instead of ad-hoc `formations.get` when posture, **`breached_files`**, or crash AI weights must match the tactical line). **Crash contest** (`BreachResolver`) and **neighbor hold** (`CombatIntrusionGeometry`) use **`ZoneOfControl.formation_id_for_zone_geometry`** for the defender’s formation dict + flank allies when the defender is an **intruder** on a host line. **`CombatEventScheduler`** (back-rank recheck + rank/file snapshots), **`AvailableActionsBuilder`** (swap partners / host **`our_formation`** / depth-spear lane dicts / same-file rank-0 ally), **`CombatResolveAction`** (formation-move formation dict), **`AttackResolver`** (depth density log), **`CombatFormationFlow.on_combatant_died`** (corpse **`slot_obstacles`** + death micro-plug + `notify` on host vs home), **`CombatEngagementResolver.resolve_close_attempt`** (defender density), and vacancy **`_combatant_from_slot_primary_living`** / compact blocking use the same geometry where **`rank`/`file`** sit on the host grid.
- **AI listed-action weights:** `CombatAIActionPicker.pick` uses `CombatTargetScoring.ai_targeting_weight_mult` (doctrine file bias, commitment, **`distributed_pressure_mult`** / **`ally_pressure_count`**, resolved **`CombatEngagementMode`**, our posture+cohesion, **opponent** formation posture+cohesion, **opponent file** `breached_files` severity via **`opponent_breach_file_targeting_mult`**, stance; harnesses **`CombatRegressionHarness._run_hostile_pair_distributed_pressure_ally_commit`**, **`_run_ally_pressure_count_depth_uses_melee_pair_to_defender`**, **`_run_hostile_pair_cached_engagement_mode_matches_live`**, **`_run_targeting_file_opposed_mult`**, **`_run_ordered_melee_opponents_file_opposed_sort`**, **`_run_targeting_formation_dict_cache_matches_live`**, **`_run_targeting_hold_lane_off_file_mult`**, **`_run_targeting_pinch_center_inward_bonus`**, **`_run_targeting_commitment_match_mult`**, **`_run_targeting_soft_geometry_eff_dist_formula`**, **`_run_targeting_prune_expired_doctrine_commitment`**, **`_run_targeting_prune_commitment_when_target_dies`**, **`_run_targeting_clear_all_state_for_dead_defender`**). **Intruders:** posture, opponent formation, breach file, and crash cohesion+posture weights read formation state via **`ZoneOfControl.formation_id_for_zone_geometry(manager, c)`** (host line), not only home `formation_id`. **Depth rank + open spear lane:** stab vs cut listing weights also scale with **`formation_doctrine`** (`pinch_center` / `hold_lane` / `probing` — `CombatConstants.DEPTH_POLEARM_AI_DOCTRINE_*`). **`CombatDoctrine`** normalizes doctrine strings; commitments clear on `set_formation_doctrine`. Harness **`CombatRegressionHarness._run_doctrine_normalize_and_manager_roundtrip`** locks normalize + manager round-trip; **`CombatRegressionHarness._run_encounter_formation_doctrine_on_start`** locks encounter + preset doctrine at **`start()`**; **`_run_ai_targeting_incap_hostile_mult`** locks incap hostile weight after **`clampf`** vs **`DOCTRINE_AI_WEIGHT_MULT_*`**; **`_run_weapon_depth_melee_eligible_fixture`** locks **`Weapon.depth_melee_eligible`** (**SPEAR** vs **SWORD** definitions); **`_run_depth_polearm_lane_open_false_for_non_eligible_weapon`** locks **`depth_polearm_lane_open`** **false** for rank>1 non-eligible weapons; **`_run_depth_polearm_lane_open_false_when_intruded`** locks the same **false** for **`ENGAGEMENT_ROLE_INTRUDED`** combatants; **`_run_depth_polearm_lane_open_false_at_rank_zero`** locks **false** at rank **0**; **`_run_depth_polearm_lane_open_false_without_living_same_file_rank0`** locks **false** when the same-file rank-0 partner is dead; **`_run_depth_polearm_lane_cache_matches_builder`** locks **`CombatDistanceBands.depth_polearm_lane_open_by_combatant_id`** vs **`AvailableActionsBuilder.depth_polearm_lane_open`**; **`_run_depth_polearm_lane_open_false_when_same_file_rank0_incap`** locks lane **false** when the same-file rank-0 is incapacitated; **`_run_depth_polearm_lane_open_zone_geometry_fid_round_trip`** locks **`zone_geometry_fid`** default vs explicit **`formation_id_for_zone_geometry`** (home + intruded host grid); **`_run_depth_polearm_allows_low_targets_strict_tight_when_lane_open`** locks **`depth_polearm_lane_allows_low_targets`** under **strict**/**tight** vs **`spear_lane_profile` open**; **`_run_stamp_attack_pair_geometry_depth_lane_flags_consistent`** locks **`stamp_attack_pair_geometry_on_dict`** depth **`pa`** fields vs those helpers; **`_run_stamp_attack_pair_geometry_depth_defaults_non_depth_attack`** locks default depth **`pa`** when not a depth-lane strike; **`_run_depth_polearm_parts_filter_tracks_allows_low`** locks **`depth_polearm_targetable_parts_filter`** vs **`depth_polearm_lane_allows_low_targets`**; **`_run_depth_polearm_parts_filter_wedge_opens_legs_strict_tight`** locks wedge-open leg path under **strict**/**tight**; **`_run_depth_polearm_restricted_profile_requires_wedge_for_allows_low`** locks **restricted** **`spear_lane_profile`** wedge-only behavior; **`_run_depth_polearm_allows_low_formation_dict_cache_matches_null`** locks **`formation_dict_cache`** on **`depth_polearm_lane_allows_low_targets`**; **`_run_depth_polearm_parts_filter_pass_through_when_no_depth_lane_use`** locks pass-through when the depth lane is not in use (rank-0 or lane closed / non-depth weapon); **`_run_depth_polearm_allows_low_assume_skips_closed_lane_guard`** locks **`assume_depth_lane_open`** vs the lane-closed early exit on **`depth_polearm_lane_allows_low_targets`**; **`_run_depth_polearm_allows_low_assume_agrees_when_lane_open`** locks **`assume`** **false** vs **true** parity when the depth lane is open; **`_run_depth_polearm_allows_low_zone_geometry_fid_round_trip`** locks **`zone_geometry_fid`** **`""`** vs explicit **`formation_id_for_zone_geometry`** on **`depth_polearm_lane_allows_low_targets`** ( **`assume_depth_lane_open` false + true** ); **`_run_depth_polearm_threatens_line_target_pure_guards`** locks **`depth_polearm_threatens_line_target`** with minimal dicts (lateral window + guards); **`_run_depth_polearm_valid_line_threat_false_when_lane_closed`** locks **`depth_polearm_valid_line_threat`** requiring **`depth_polearm_lane_open`** even when **`depth_polearm_threatens_line_target`** is **true**; **`_run_depth_polearm_valid_line_threat_agrees_with_threatens_when_lane_open`** locks **`depth_polearm_valid_line_threat`** vs **`depth_polearm_threatens_line_target`** when the lane is open (every living enemy); **`_run_depth_polearm_opp_matches_rank0_agrees_with_valid_line_threat`** locks **`AvailableActionsBuilder._opp_matches_melee_rank_target(..., 0)`** vs **`depth_polearm_valid_line_threat`** on the same layout; **`_run_depth_polearm_melee_pair_rank_allowed_agrees_with_valid_line_threat`** locks **`_melee_pair_rank_allowed`** vs **`depth_polearm_valid_line_threat`** (open **3-wide** + closed lane).
- Balance and state names: `combat/CombatConstants.gd` (intentionally large). **Tier 3.1 strike measure:** `STRIKE_MEASURE_*`; `AvailableActionsBuilder.strike_measure_ratio_for_attack_pair` (wind-up / resolve after `stamp_attack_pair_geometry_on_dict`). **Surround:** `TacticalCombat.surround_defense_multiplier_from_pa_with_sector`; production path gated by **`CombatConstants.is_feature_sector_surround_load`** (default **false**; **`set_feature_sector_surround_load`** for harness soaks). ## Core / UI

- Entity model: `core/` (e.g. `CoreEntity.gd`, `EntityDamage.gd`, …).
- Battle UI: `ui/BattleScene.gd` and related `ui/*Battle*`, `ui/*Combat*`, `ui/*Formation*`.

When changing combat flow, prefer editing the **focused module** rather than inflating `CombatManager.gd`.

Debug: `COMBAT_EVENT_DEBUG` enables turn-summary `[Combat.Flow]` lines; add `COMBAT_EVENT_DEBUG_VERBOSE` for per-action lists and formation/incursion spam (`CombatConstants.gd`). Player lead is flagged on `Character` via `is_party_leader` (scene + `PlayerCompanionSetup`); combatants carry `is_party_leader` from `CombatManager.register`. Headless harness: `godot --headless --path <project> -s res://scripts/run_combat_regression_harness.gd` → `CombatRegressionHarness.run_all()`. In this repo, set **`godotTools.editorPath.godot4`** in **`.vscode/settings.json`** (Godot Tools) and run the VS Code task **Run Combat Regression Harness (headless)** from **`.vscode/tasks.json`**.

**Combat documentation:** **`docs/IMPLEMENTATION_ORDER.md`** — **Last verified**, milestone **Status**, **Development gate**, dependency chain (**authoritative**; do not mirror milestone tables in `AGENTS.md`). Topic index: **`docs/README.md`**. Tier 1 field/plug **spec:** `docs/ENGAGEMENT_LINE_COHESION_INTRUSION_PLAN.md` §4–§6 (§2 mirrors the plan’s Tier 1 column).

**Combat code map:** `.cursor/rules/fallen-paths.mdc` (subsystem list). **`FEATURE_LINE_CRASH_INTRUSION`** (`CombatConstants.gd`, default **`false`**) — plan **Development gate**. **Intruder host formation id** (ZoC **`assign_combatant_zones`**, **`count_alive_in_zone`** zone fill, engagement parry, pair geometry, AI weights): **`ZoneOfControl.formation_id_for_zone_geometry(manager, c)`**. **Tier 3.0** kinematics: `WeaponConstants` (`kinematic_delivery`), `WeaponDamageHelper`, `WeaponSwingPhysics` — see plan **Tier 3** + dependency item **12**.
