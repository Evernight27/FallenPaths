# scenes/

Godot scenes (recipes). Scripts co-located where entry-local.

| Path | Contents |
|------|----------|
| `campaign/main.tscn` | Campaign boot (project main scene) |
| `actors/player.tscn` | Party lead + companion slots |
| `actors/enemy.tscn` | Enemy actor template |
| `actors/character.gd` | CharacterBody script used by player/companions |
| `battle/battle.tscn` | Battle shell → `ui/battle/BattleScene.gd` |
| `ui/` | Reserved for extracted UI packed scenes |
